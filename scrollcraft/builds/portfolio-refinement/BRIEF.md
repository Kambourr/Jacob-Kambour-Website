# Portfolio refinement brief

## Authority and evidence
Existing brief reused, with user-selected scope: “Refine the existing layout (Recommended)”. User goal: “a recruiter can learn about me and see what I have done within 15 seconds”. Direct sections, existing Stokt-inspired presentation, compact scrolling menu, and new-tab project links are established preferences. This is an incremental improvement, not a new cinematic site.

## Eight decisions
1. Vibe: clear, technical, composed, tactile. Authored interpretation of existing site and recruiter brief.
2. Journey: identity and current roles; one real project; experience and education; about; contact. Existing sequence preserved.
3. Energy: restrained opening, quiet credentials, project as focal point, calm factual background, confident contact. Authored pacing.
4. Remember: the real Tesla dashboard linked to the three steps that produced it. Desired response: “I understand what Jacob built.”
5. Signature: a project workflow inspector connecting Public filings, Historical forecasts, and Checked commentary to a factual explanation. Buttons and keyboard selection provide agency without changing or fabricating dashboard data.
6. Range: refine existing layout, explicitly selected by user. Petrol, mint, cream and existing fonts retained.
7. Separate natural-flow sections, inherited from current site. No pinned reading, scroll interception, or delayed essential copy.
8. Assets: existing actual dashboard PNG; CSS technical drafting lines and semantic workflow labels. No generated imagery, stock photography, video, or spend.

## Feeling curve, before score
Recognition: name, discipline and real current roles are visible at arrival.
Orientation: quiet credential strip confirms background.
Understanding (peak): dashboard plus selectable process explanations makes the project concrete.
Confidence: unchanged resume-backed bullets and education remain fully visible.
Connection: about prose and direct contact end with a clear action.
Peak sentence: “It’s the site where I could inspect how his Tesla finance project moves from filings to checked commentary.”
No authored empty scroll or forced dwell.

## Grammar
Custom factual portfolio exhibit. Fixed compact disclosure navigation, split semantic hero with real artifact, natural-flow project inspection, fully readable experience, contact plate ending. Bans: pinned acts, fake dashboard UI, text hidden behind animation, cinematic video, generic slogans. The eight stock grammars do not fit intact: filmic and continuous world delay recruiter access; editorial removes the requested bar; live surface misrepresents a portfolio as an app; poster underuses project evidence; gallery assumes multiple objects and removes identity; split stage assumes a comparison; cutlist introduces unnecessary visual intensity.

## Layer contract
Far: fine technical grid with low contrast, static. Mid: orbital drafting lines with small scroll parallax. Subject: actual dashboard with restrained independent translation. Foreground: a clearly labelled workflow note, slightly stronger translation. Type/controls: stable semantic text. Layers overlap only in the artifact column, never over the headline. Mobile removes decorative orbital lines and simplifies the foreground placement. Reduced motion keeps a complete still composition.
